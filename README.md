# Creative Portfolio — Kendall Angulo

This separate repository preserves the sections removed from [the Unity gameplay programming portfolio](https://kendarte.github.io/). **It is not the main Unity CV or hiring portfolio.**

## Contents

- `/3d/` — 3D characters, scenic and cinematic work and animation
- `/illustration/` — illustration and visual development
- `/commercials/` — video and promotional projects, including the original multimedia assets
- `/projects/siza/` — experimental Siza RPG hub
- `/siza-mobile-test/`, `/siza-core/`, `/siza-world-engine/`, `/siza-card-generator/` — Siza web experiments and supporting files
- `/rivarica/` — world book, character resources and atlas
- `/projects/euclid-wars/` — Euclid Wars, removed from the main homepage's featured project list
- `/media/` — supporting media included with these pages

## Hosting

Prepared as a standalone GitHub Pages **project repository** called `creative-portfolio`.

Once published at `https://kendarte.github.io/creative-portfolio/`, enable Pages from branch `main`, folder `/(root)`.

## Scope and provenance

Source material was copied from the existing public GitHub Pages repository, preserving media and source pages. URL prefixes have been adjusted for an independent project path. Neither the original repository nor its deployed files were deleted or overwritten.

Some interactive prototypes may use external services. Their remote dependencies must be independently available for every feature to work.
